# Dopamine Cloud Lite V1.0 设计冻结

| 决策项 | 结果 |
|---|---|
| 产品线 | 与 Dopamine Local V8.x 并行；独立 GitHub / Worker / D1 / 域名 |
| 前端 | 直接复用 V8.0.4 JS/CSS/UI；不引入 React 迁移成本 |
| 运行架构 | 单个 Cloudflare Worker 静态 Assets + API + D1 |
| 账号 | admin01/admin02/admin03；高熵随机密钥；平权增删改查 |
| 注册、找回、权限 | 暂无 |
| 存储 | D1 `shared_document` 单行、单 JSON，version=4 |
| 保存 | 手动和 5 分钟自动；dirty 才自动写 |
| 读取 | 初次登录 + 5 分钟轮询；本地无修改时按最新云端刷新 |
| 编辑锁 | 无 |
| 冲突 | Last Write Wins，整份 JSON 后保存者覆盖前保存者 |
| 关闭标签 | 原生 beforeunload 提示，不自动保存 |
| 应用退出登录 | 未保存数据时支持 保存并退出 / 不保存退出 / 继续编辑 |
| 数据互通 | 与 Local V8.x 相同 JSON；手动导入、导出、整体替换 |
| 文件服务 | 不使用 R2 |
| 安全 | HttpOnly Secure SameSite=Lax cookie、D1 session token hash、HMAC 强密钥验证、Origin CSRF 拦截、账号限速 |
| 运行时依赖 | Workers 平台 API；Wrangler 为开发/部署工具 |
| 免费限制 | D1/Workers Free quotas；Cloudflare 非大陆稳定性承诺 |

升级到下一期最有价值的两个优化：**按项目级行存储以缩小 Last Write Wins 冲突范围**、**支持服务器端可恢复快照/导出计划**。用户目前明确不要求锁定/实时协作，本次不实现。

## 项目视图状态

项目、套餐下拉当前选中项属于**本账号浏览器的 UI 偏好**，使用 Cloud 独立 localStorage key 保存选择器状态，不产生一次业务数据写入，也不会强制其他账号跳转项目。业务数据仍全部存在 D1；浏览器 localStorage 不存业务数据。
