# Dopamine Cloud Lite V1.0.2 — 当前技术设计

## 产品形态

- Dopamine Local V8.x：独立静态网页 / localStorage 数据，不覆盖。
- Dopamine Cloud Lite：`fryjin/DLO` / Cloudflare Worker 静态资源 + API / D1，三个固定登录账号。
- 账号别名：炮台 = `admin01`，芋头 = `admin02`，EE = `admin03`。原三组随机登录密钥、`KEY_PEPPER` 不变。
- 三个账号平等，可以管理**自己的**所有项目、商品、组合、套餐；可以查看另外两个人的数据，但不能直接改。

## 持久化

- `users`、`sessions`、`login_limits`：账号及会话。
- `account_documents`：三行数据，每行 `user_id` 为主键、`data_json` 包含该账号全部项目及套餐、`version` 为该账号版本号、`updated_at`、`updated_by`。
- `shared_document`：V1.0.1 旧共享数据表，升级迁移时只读一次用于初始化个人副本，之后保留不变；不再作为业务数据源。
- 数据迁移：`0002_account_documents.sql` 把旧共享数据分别复制到三个已初始化账号，只插入缺失行。

## API 和权限边界

| API | 身份 | 作用 |
|---|---|---|
| `POST /api/login` | 无 | 固定账号密钥验证 |
| `GET /api/me` | 已登录 | 当前身份 |
| `GET /api/state` | 已登录 | 返回本人文档 |
| `GET /api/state?owner=admin02` | 已登录 | 返回指定账号文档，只读 |
| `POST /api/state` | 已登录 | 保存**本人行**，由 Cookie 中的身份确定目标；拒绝请求指定其他 owner |
| `POST /api/state/sync` | 已登录 | `{source:'admin02'}`，将对方已保存文档使用单条 D1 SQL 原子复制到**本人行**，不得修改对方 |
| `POST /api/logout` | 已登录 | 会话失效 |

## 前端行为

- 顶部新增「数据空间」切换器。浏览他人时禁用所有业务输入、新增、删除、保存、导入、批量粘贴操作；仍可查看、搜索、选择项目/套餐、导出 JSON。
- 只有在他人只读模式才出现「同步到我的数据」按钮，点击后弹窗明确警告覆盖自己当前全部数据，确认才同步。
- 本人未保存的数据不能直接切换查看他人：提示先保存或取消修改。
- 每五分钟刷新当前查看空间；仅本人空间有待保存改动时自动保存。页面关闭不静默上传。
- 同一账号多设备编辑仍采用 Last Write Wins；不同账号普通保存互不影响。
- JSON 导入/导出结构仍为 `version:4`，兼容 Dopamine Local V8。

## 排除项

无实时协同、编辑锁、成员邀请、分层权限、自动备份/版本恢复、云端数据双向实时同步。D1/Worker 免费额度和大陆网络可访问性需按实际情况核验。
