# Dopamine Cloud Lite V1.0.10 表头消失修复

## 问题描述

在套餐售价计算页滚动到产品表末尾，或折扣利润汇总区域时，原始表头被固定的套餐工具栏盖住，但数据行仍显示。产品信息设置长表存在同类情况。

## 根因

- 既有样式让表格滚动容器 `overflow:auto`；`th { position:sticky;top:0 }` 的作用范围限定在该容器内。
- 当浏览器外层滚动条滚动时，该容器连同表头被移动到固定工具栏之后；原表头的粘性定位不能跨出它的容器。
- 旧的 `contain:paint` 进一步增加浏览器分层复杂性，但不是业务数据消失，也不是 `renderProducts()/renderSummary()` 没生成表头。

## 方案

1. 内部滚动：保留原生 sticky，顶部表头在容器内可用。
2. 外部滚动：如果表格顶部已被工具栏遮住、数据行仍能看见，显示一份只读镜像表头。镜像按源表第一行实际列宽生成 colgroup，源滚动容器水平位移实时同步。
3. 镜像 `aria-hidden`、`pointer-events:none`，不重复编辑控件和事件，不会改变项目状态/触发云端保存。
4. 画面离开当前表格、切换页面、滚回表头可见范围时，镜像自动隐藏。
5. 第二层折扣表头独立 sticky 偏移，使用首行实际高度。
6. 滚动容器移除重复 `contain:paint`，区块外层保留绘制隔离阻止向上穿透。
