# Dopamine Cloud Lite V1.0.5 — 响应式吸顶位置修正

## 问题根因

V1.0.4 的 `contain: paint` 只约束表头绘制，却未解决**工具栏与标题栏之间的实际吸顶空隙**。
当窗口 CSS 宽度 ≤1600px 时，`.page-head` 自身把 `--subhead-h` 改为 88px；
当宽度 ≤1200px 时又改为 78px。但它的兄弟元素 `.toolbar` 不继承此变量，
仍使用根元素上的 98px，因此在标题栏与工具栏之间出现 10～20px 空隙，
用户截图中的折扣输入框、表格表头恰好从空隙露出。

## 修复

`v8.css`：在相应媒体查询中直接调整 `:root{--subhead-h:...}`，
`.page-head` 高度与 `.toolbar` 吸顶位置共同使用这一根变量。
保留 V1.0.4 表格裁切，避免改动内部可滚动表格。

## 验收

- `npm run check`：通过，包含五项 Worker 单元测试、JS 语法检查、前端构建。
- `python tests/sticky_offsets_regression.py`：通过，包含正常宽度、近似浏览器缩放模式、1024px、900px；
  在不同滚动位置检查标题栏与工具栏无吸顶间隙，并验证表格自身 sticky 表头保持正常。
- 真实 Cloudflare 生产环境仍需部署后验收；本次变更未触及 Worker / D1 / 用户账号信息。

## 部署

1. 解压全量源码 ZIP，覆盖 `fryjin/DLO` 同名文件并提交 `main`。
2. 等待 Cloudflare Worker 自动部署成功。
3. `Ctrl + F5` 强制刷新，检查两个页面顶部（含折扣输入框）不再出现穿透。

无需执行 D1 迁移，无需修改 `KEY_PEPPER`。
