# Dopamine Cloud Lite V1.0.3 — 顶部精简与左下角账号入口

## 修改范围

- 移除顶栏「取消修改」「同步最新」操作及对应客户端事件代码。
- 保留「保存」、云端自动保存及 5 分钟读取最新数据的定时任务。
- 登录账号名称从顶栏移到左侧导航底部：圆形头像显示炮 / 芋 / EE，点击打开账号菜单（身份、退出登录）。
- 小屏（原侧栏隐藏时）左下角保留可用的悬浮账号入口。
- 查看他人时，数据仍只读；「同步到我的数据」仍需要二次确认，服务端只允许修改本人数据。
- 退出登录若有尚未保存的修改，仍可选择保存并退出 / 放弃修改退出 / 继续编辑。

## 升级部署

1. **建议先从当前已验收的 V1.0.2 云端版本导出 JSON 备份。**
2. 解压 V1.0.3 完整代码包，覆盖上传至 `fryjin/DLO` 新仓库 `main`。
3. 等 Cloudflare Workers Builds 构建部署成功，强制刷新页面；检查账号头像、登录菜单与保存。
4. 不需要再次执行 D1 SQL，不需要重置 Worker Secret 或账号密钥。

## 验收建议

1. 炮台、芋头、EE 逐一登录，左下角圆形头像显示对应文字，点开可见全名和退出登录。
2. 顶栏没有取消修改、同步最新、当前账号名字、退出登录按钮。
3. 编辑本人产品后保存，刷新仍在。查看他人数据仍只读。
4. 同步他人到本人仍弹出覆盖确认；取消无影响。
5. 有未保存修改时从左下头像菜单退出，显示三选项；退出成功后可正常重新登录。
6. 在 1920、1440、1280 和 1024 宽度检查头像及弹出菜单可点击且不越界。

## 行为说明

没有「取消修改」按钮后，如要放弃当前未保存的更改，可使用头像菜单「退出登录 → 不保存退出」，或刷新页面并在浏览器原生提醒中确认离开。注意自动保存每五分钟运行，因此不应依赖退出流程撤销此前已自动保存的更改。
