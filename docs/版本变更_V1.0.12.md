# Cloud Lite V1.0.12 — 组合单价调整与列宽优化

## 规则

- 组合的 `priceAdjustment` 为**单组价格加减值**，例如 `+0.10`、`-0.20`；缺失时默认 `0`。字段仅适用于 `type: "combo"`。
- 最终组合售价 = 所有成份最终售价 × 各成份数量之和 + `priceAdjustment`。组合成本仍为所有成份成本 × 数量之和。父组合调用子组合最终售价。
- 组合最终价格不能小于 0。正负调整值不改变产品成本；套餐折扣、利润引用最终组合售价。
- 普通产品不允许修改调整值，保留原有单品标价输入。
- 只读空间不能修改调整值；如需复制他人数据仍走原有确认覆盖流程。
- 产品批量表新增调整值列，旧 6/7 列兼容；可按列粘贴组合调整值。

## 视觉

产品表采用固定列宽比例，产品品类 16%、成份 17%，成份摘要换行并撑高行高，新增调整值 9% 列。过窄窗口使用产品表自己的横向滚动区域。

## 数据兼容与部署

`version:4` JSON 新增可选字段，不改变 D1 schema，不需 SQL。**旧 Local V8.0.4 尚不能按调整值计算售价与利润**，如需跨端完全一致，需后续升级 Local 计算引擎。解压全量覆盖 GitHub DLO `main`，Worker 自动部署。

- 新版 8 列批量导出导入、旧版 7 列兼容、他人空间只读。
