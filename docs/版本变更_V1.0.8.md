# Dopamine Cloud Lite V1.0.8 — 保存状态与黄灰绿视觉更新

## 本轮需求

1. 自动保存成功后，更新显示为「自动保存 HH:MM」。
2. 手动保存成功后，更新显示为「手动保存 HH:MM」。
3. 项目全站更换为协调的黄灰绿配色，同时保留错误和危险操作的红色警示。

## 保存逻辑

- `persist("auto")` 只有当本人的页面 `dirty=true` 时才发送写入；写入成功后用服务端 `updatedAt`（如不存在则用本机提交完成时刻）更新状态。
- `persist("manual")` 在请求成功后同样更新时间与操作类型。
- 时间使用浏览器 `zh-CN`、24 小时 HH:MM 显示；不把浏览器时刻硬编码成云端 UTC。
- 五分钟周期未修改时，仍检查当前浏览数据空间的新数据，但不提交无意义的整份 JSON，以免增加 D1 写入和同账号多标签覆盖风险；此时保存时间**保持为最近一次成功保存时刻**。
- 保存失败不伪造成功时间；有未保存修改继续显示明确提示。
- 页面刷新后读取到服务端 `updatedAt`，由于 D1 尚未记录保存行为类型，仅显示「上次保存 HH:MM」而非猜测自动/手动。
- 他人只读空间依旧显示只读提示，禁止写入；跨账号复制成功后标示「同步完成 HH:MM」。

## 配色方案

| 角色 | 颜色 | 用途 |
|---|---|---|
| 暖灰背景 | `#F4F5F0` | 工作区底色 |
| 白色 | `#FFFFFF` | 表格 / 卡片，保持信息密度 |
| 鼠尾草绿 | `#416E50` | 保存、新增组合、登录、选中导航 |
| 深绿色 | `#305A40` | 悬停与关键操作 |
| 浅绿灰 | `#E9F2E8` | 导航选中与自动计算区域 |
| 芥末黄 | `#D4A63A` | 已手动保存状态、局部强调 |
| 米黄色 | `#FFF4D6` | 折扣表头、组合标记、次级重点 |
| 深文字色 | `#26342C` | 主要文本 |
| 警示红 | 保留原有 | 错误、不可恢复的同步覆盖等危险操作 |

## 验证

- `node --check app.js` + `npm test` + `npm run build`。
- `python tests/save_status_v108.py`：在 Chromium 模拟 Worker 环境验证手动/自动标签时间、5 分钟定时、没有变更不重复写入、窄屏状态可见、只读模式禁止保存。
- `python tests/browser_dom_smoke.py` + `python tests/view_space_reload_regression.py`：验证账号隔离、只读浏览、同步确认与浏览偏好。
- `python tests/sticky_offsets_regression.py` + `python tests/sticky_header_regression.py`：验证此前修复的表头吸顶间隙没有复发。
- `python tests/theme_visual_v108.py`：Chromium 1440/1024/900px 页面截图检查；截图文件仅用于本地验收，不加入 GitHub 部署包。
- **尚未在真实 Cloudflare 生产环境部署**，实际站点需要人工验收一次。

## 发布

1. 先从 Cloud Lite 本人数据空间导出一份 JSON 备份。
2. 将 V1.0.8 完整源码解压后覆盖上传 `fryjin/DLO` 仓库 `main`（不要直接上传 ZIP 文件）。
3. Cloudflare Worker Builds 完成后 Ctrl+F5 刷新，验证本人手动保存和五分钟自动保存标签。
4. 查看他人空间仍隐藏保存/备份，可浏览套餐；检查三个账号数据不互相覆盖。

无需 D1 migration、无需配置新的 Worker Secrets，也不会修改原来独立部署的本地版。
