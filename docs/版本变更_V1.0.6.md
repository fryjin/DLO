# Dopamine Cloud Lite V1.0.6 — 本人数据空间专属保存与备份

## 需求落实

| 数据空间 | 保存 | 数据管理 | 导出备份 | 恢复备份 | 查看 | 同步到我的数据 |
|---|---|---|---|---|---|---|
| 我的空间 | 显示 | 显示 | 允许 | 允许 | 允许 | 不适用 |
| 他人空间 | 隐藏 | 隐藏 | 禁止 | 禁止 | 只读 | 允许（必须确认覆盖） |

## 实现

- `updateSpaceControls()` 切换数据空间时同时控制 `#saveBtn` 与 `#dataMenu` 的显示，进入他人空间立即收起已展开的数据管理菜单。
- `v8.css` 对隐藏属性和他人空间均明确 `display:none!important`，覆盖各屏幕宽度样式。
- `backupBtn`、`restoreBtn`、`restoreInput` 事件处理添加 `loaded`、`spaceSwitching`、`isOtherSpace()` 校验；文件异步读取后再次验证所属空间，避免切换期间误应用。
- Worker 保持本人数据写入限制；他人同步按钮与二次确认未改变。

## 部署

解压覆盖 GitHub `fryjin/DLO` 仓库 `main` 分支，等待 Cloudflare Workers Builds 自动部署。**无 D1 迁移，无登录密钥更新。**

## 建议验收

1. 本人空间可见「保存」「数据管理」，能够导出备份。
2. 选择其他账号后两按钮完全消失；不能通过隐藏入口直接触发备份。
3. 其他账号空间可正常只读浏览，并显示「同步到我的数据」，点击弹确认。
4. 切回本人空间，两按钮重新出现且功能正常。
5. 自动保存自己编辑的内容及每 5 分钟后台刷新保持正常。
