# Dopamine Cloud Lite V1.0.4 — 表头裁切修复

## 修复内容
- 产品信息设置：表头不再透出到搜索/新增产品工具栏上方。
- 套餐售价计算：折扣价小计/商品利润小计等表头不再露出到套餐工具栏上方。
- 只在对应表格滚动区域内绘制 sticky 表头，保留横向滚动及长表格表头吸顶。
- 仍保留 V1.0.3 的三个账号独立数据、只读查看、复制覆盖同步以及五分钟保存/刷新。

## 发布
1. 将此完整压缩包解压，覆盖上传到 `fryjin/DLO` 的 `main`。
2. 等待 Cloudflare Workers Builds 自动部署。
3. 强制刷新浏览器以加载更新后的 CSS（Ctrl+F5）。
4. 依次在产品信息设置和套餐售价计算中纵向滚动页面、横向滚动表格，确认粘性表头不会越界。

无 D1 schema/API 或密钥变更。不需要执行 SQL。
