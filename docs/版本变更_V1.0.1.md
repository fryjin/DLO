# Dopamine Cloud Lite V1.0.1 版本变更与部署

## 修改
1. 会话初始化期间只显示中性启动界面；验证成功后显示工作台，验证失败后显示登录面板，刷新不再短暂闪现登录表单。
2. 三个登录账号界面分别改为「炮台」「芋头」「EE」，后端将其安全地映射到既有的 `admin01/admin02/admin03`，密码校验依然使用既有内部账号和 HMAC。
3. 接口继续返回内部用户名，同时附加 `displayName`；登录显示友好名称，旧会话刷新也正确显示。

## 兼容性
- 复用原有三组密钥、`KEY_PEPPER`、D1 `users`、`sessions`、`shared_document`。
- 不执行 SQL，不重置账号，不清空业务数据。
- 本次 ZIP 的 `wrangler.jsonc` 已配置生产 D1 的原数据库 ID。
- 前端输入通过选择框限制为三个名字；原 `admin01/admin02/admin03` 仍可通过 API 登录以兼容现有集成。

## 部署步骤
1. 在原 Cloud Lite 中先导出一次 JSON 备份。
2. 将压缩包解压后的全部文件（不含私有密钥）上传到新仓库 `fryjin/DLO` 的 `main` 分支，覆盖同名文件，保留目录结构。
3. 原 Cloudflare Workers Builds 自动发布完成后，访问已有的 `dopamine-cloud-lite` Worker 地址。D1、KEY_PEPPER 不要修改。
4. 已登录状态下刷新：只显示短暂的「正在验证登录状态…」，不应闪出账号/密钥表单，右上角显示「炮台」等友好名称。
5. 退出登录后，使用新的账号下拉选项「芋头」「EE」配合对应原密钥登录，检查跨账号读写及数据不丢失。

如 Worker 运行时没有网络响应，启动遮罩会等待请求失败后显示登录表单及错误消息，不会无期限阻止错误提示。
