# Dopamine Cloud Lite V1.0.11 — 标题单行化与页面空间优化

## 变更

- 产品信息页：`工作台 / 产品信息管理`，不再单独占第二行放大标题。
- 套餐售价页：`工作台 / 套餐售价计算`，与产品页统一视觉。
- 页面头部高度由 98 / 88 / 78px 精简为 56 / 50 / 48px（依屏幕宽度），使下面的统计、工具栏及表格上移。
- 使用同一 `--subhead-h` 变量控制 sticky 页面头和工具栏的偏移，避免重现表头穿透。

## 保留

V1.0.10 的固定/浮动表头方案、三账号数据隔离、只读切换、手动同步确认、红白蓝主题、五分钟自动保存规则及数据结构均保持不变。

## 部署

完整解压覆盖至 GitHub `fryjin/DLO` 的 `main`，Cloudflare Workers Builds 自动部署；线上 Ctrl+F5 刷新。无需任何 D1 迁移、Worker Secret 或登录账号更改。

## 验收

- 两个页面分别呈现指定的完整单行标题；页面内容明显上移。
- 切换页面、滚动表格、表格横向滚动后，表头正常显示且不穿透上方工具栏。
- 本人/他人数据权限、保存状态和账号菜单正常。
