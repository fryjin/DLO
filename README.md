# Dopamine Cloud Lite V1.0.12 — 组合单价调整及产品表格列宽优化

**基于 V1.0.11 完整源码开发，可覆盖部署至独立云端仓库 `fryjin/DLO`。**

## 本轮功能

1. **组合产品「单价调整值」**：新增位于「单个成本」与「单品标价」之间的独立输入列，仅组合产品可编辑。支持 `+0.15`、`-0.05`、`0` 等有符号金额，单位为元/组。
   - `组合最终单价 = Σ(成份最终单价 × 成份数量) + 单价调整值`。
   - 普通产品依然使用原有「单品标价」，调整列显示 `—`。
   - 组合成本 **不受调整值影响**；组合利润 = 调整后的最终单价 - 组合成本。
   - 嵌套组合使用子组合**已调整后的最终单价**，套餐原价、折扣价、商品利润、套餐利润及汇总均随之联动。
   - 使用原有 BigInt 12 位定点计算，仅展示时按原规则舍入。
   - 不接受使自身或上层嵌套组合最终单价小于 0 的调整值；源产品降价导致负价组合时也拒绝提交。弹出错误提示、恢复上次有效数值。
2. **表格列宽和换行**：调整产品信息表的固定列宽分配，产品品类约 16%、成份约 17%（按表格总宽度计算），避免旧版成份列占用大面积空白。长成份按单元格宽度自动换行，行高随内容增长；其他字段仍采用紧凑单行输入。
3. **批量复制/粘贴兼容**：新版产品 TSV 增加「单价调整值」一列（8 列），可保存并再次粘贴正负调整值；旧版 7/6 列及简表继续识别。单列模式也新增该字段，仅组合允许填写，报错时整批原子回滚。
4. **旧数据向后兼容**：沿用原 `version:4` JSON，新增可选 `priceAdjustment` 字段；旧数据自动视作 `0`。D1 使用原 `account_documents` JSON 列，无需迁移 SQL。三账号权限、跨账号查看、显式覆盖同步以及五分钟自动保存均保留。

## 重要兼容说明

Dopamine Cloud Lite V1.0.12 的 JSON 可以导入导出，且仍兼容旧 `version:4` 结构。**但是现有 Dopamine Local V8.0.4 的计算引擎尚不知道 `priceAdjustment` 字段：将含有组合调整值的 JSON 导入旧本地版后，旧本地版不会把调整值计入组合售价及利润。** 要在本地版获得完全一致的计算结果，必须后续同步升级本地版组合计价逻辑；本轮不覆盖原本地版本。

## 部署

1. 先在当前云端版为需要保留的数据空间执行「数据管理 → 导出备份」。
2. 解压本完整 ZIP，覆盖上传至独立 GitHub 仓库 `fryjin/DLO` 的 `main`。
3. 等待 Cloudflare Workers Builds 自动部署；网页使用 `Ctrl + F5` 刷新。
4. 无需修改 D1、Worker Secret、账号或登录密钥；其他账号的独立数据保留。

## 上线验收要点

- 新建组合，输入 `+0.20` / `-0.10`，查看最终单品标价、利润和套餐折扣结果是否同步变化。
- 组合引用另一个组合时，子组合调价是否进入父组合最终售价。
- 输入导致负价的调整值应提示错误且不能保存。
- 成份文字过长应换行，表格不再把空白成份列撑宽。
- 复制 8 列产品表后导入新项目，组合调整值是否保留；旧 7 列是否仍可粘贴。
- 查看他人空间时调整输入不可编辑，保存和数据管理仍隐藏。
- 表头滚动、单行标题及五分钟自动保存行为保持 V1.0.11 的逻辑。
