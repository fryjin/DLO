# Dopamine Cloud Lite V1.0.11 — 标题单行化与页面空间优化

基于 **V1.0.10** 的完整表头滚动修复版本，本轮仅压缩标题区：统一显示「工作台 / 产品信息管理」与「工作台 / 套餐售价计算」，删除重复的两层标题布局，将下方模块上移。**保存时间问题仍不处理**；不修改数据结构、权限、Worker API、保存逻辑和业务计算。

## 本轮变更

- 标题从「工作台 / 产品管理」与「产品信息设置」两行改为「工作台 / 产品信息管理」单行；套餐页面显示「工作台 / 套餐售价计算」。
- 缩减标题吸顶区高度：桌面 56px，≤1600px 为 50px，≤1200px 为 48px，让统计卡片或套餐工具栏上移约 30–42px。
- **同步修改 sticky 工具栏偏移的共享 CSS 变量**，避免标题区缩短后再次出现工具栏与标题栏间隙及表头穿透。
- V1.0.10 的浮动表头、表格内部滚动与红白蓝主题保持不变。

## 上一轮 V1.0.10 保留的表头修复

- **定位到真实原因**：表格有独立的纵向滚动容器；当用户同时向下滚动外层页面时，`sticky th` 仍局限于内部滚动容器，容器头部滑进固定工具栏背后，数据行仍留在视口内，因此表头看起来“消失”。原测试只覆盖内部滚动，未覆盖外层滚动与横向滚动组合。
- **双层滚动适配**：表头可见时保持原有原生 sticky；当原表头被上层工具栏遮挡，而表格行仍可见时，在工具栏正下方显示一份自动对齐、只读的表头镜像，随实际表格横向滚动同步。表格离开视口后镜像自动消失。
- **覆盖的表格**：产品信息设置表、套餐产品表、套餐费用表、折扣与利润对比表。镜像不允许编辑，也不会访问数据库或创建额外保存请求。
- **两级折扣表头**：第二行子标题单独使用首行高度作为 sticky top 偏移，避免两层相互覆盖。
- **去掉滚动容器内重复的 `contain: paint`**：仍保留表格区块外层的绘制隔离，避免前期出现的表头穿透到工具栏。
- **无业务变更**：沿用红白蓝主题、三个独立数据空间、5分钟自动保存和数据空间复制确认流程。

## 部署

将本 ZIP 解压后覆盖上传至全新云端仓库 `fryjin/DLO` 的 `main`，Cloudflare Workers Builds 自动构建部署。部署完成后请在浏览器使用 Ctrl+F5 强制刷新。

**无需 D1 SQL 迁移，无需修改 `KEY_PEPPER`、登录密钥或 Worker 绑定。** 原有三个账号及其独立数据保留。

## 校验

```bash
node --check app.js
node --check src/worker.js
npm test
npm run build
```

本次修改仅限 UI 层 JS/CSS、版本标签和测试脚本；Worker、D1、SQL 文件完全不变。

本地 Chromium 已覆盖 1817 / 1440 / 1024px 多滚动场景；线上 F5 刷新和真实业务数据仍需你部署验收。

## 安全与边界

- 保存及备份/恢复只能操作本人数据空间；查看他人数据时只读，并隐藏保存及数据管理按钮。
- 浏览他人项目和套餐时允许切换；刷新保持当前浏览位置。
- 数据同步到本人仍需要显式确认覆盖。
- 五分钟自动保存及同步检查机制保持不变。
- 本地 Pricing Web 与 Cloud Lite 两套项目保持独立，使用兼容 JSON 手动导入导出。
