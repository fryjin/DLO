# Dopamine Cloud Lite V1.0.9 — 红·白·蓝主题

本版本在已验收的 **V1.0.8** 基础上，仅调整前端 UI 配色，不修改账号权限、数据结构、Worker API、保存逻辑、套餐及产品计算方式。

## 本轮变更

- **白色为主**：卡片、表格、弹窗维持洁净白底；外层背景统一为冷调浅灰白 `#F5F7FB`。
- **稳重蓝色为主操作色**：按钮、导航选中、可编辑聚焦、成本自动计算底色、利润和自动保存状态统一为蓝色系 `#315F9D`。
- **柔和红色为强调色**：组合产品标签、折扣列/折扣对比、手动保存状态统一为低饱和红色 `#C34859`；删除和覆盖确认继续使用更明确的红色危险状态。
- 保持产品信息设置、套餐售价计算、登录页、数据空间选择、左下角账号入口及确认弹窗的布局、结构与全部交互。
- **保存文案保持**：「自动保存 HH:MM」「手动保存 HH:MM」，不会因为主题变更修改数据保存时机。

## 部署

将本 ZIP 解压后覆盖上传至全新云端仓库 `fryjin/DLO` 的 `main`，Cloudflare Workers Builds 自动构建部署。部署完成后请在浏览器使用 Ctrl+F5 强制刷新。

**无需 D1 SQL 迁移，无需修改 `KEY_PEPPER`、登录密钥或 Worker 绑定。** 原有三个账号及其独立数据保留。

## 校验

```bash
node --check app.js
node --check src/worker.js
npm test
npm run build
```

本次仅对样式、HTML 版本标签及说明文档做修改，未改动 JavaScript、Worker、D1、SQL 文件。线上视觉效果需部署后验收。

## 安全与边界

- 保存及备份/恢复只能操作本人数据空间；查看他人数据时只读，并隐藏保存及数据管理按钮。
- 浏览他人项目和套餐时允许切换；刷新保持当前浏览位置。
- 数据同步到本人仍需要显式确认覆盖。
- 五分钟自动保存及同步检查机制保持不变。
- 本地 Pricing Web 与 Cloud Lite 两套项目保持独立，使用兼容 JSON 手动导入导出。
